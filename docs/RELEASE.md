# Release Checklist

Before calling a version shareable:

- [ ] `SKILL.md` has valid frontmatter and precise trigger conditions.
- [ ] README explains the problem, solution, usage, and limitations.
- [ ] Product, safety, examples, and test-plan docs are current.
- [ ] Private endpoint, credential, and personal-data scan passes.
- [ ] At least one representative example has been validated.
- [ ] External side effects have explicit approval gates.
- [ ] License and attribution requirements are documented.
