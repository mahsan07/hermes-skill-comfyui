# Contributing

Keep changes focused and easy to review.

1. Explain the user problem and the smallest change that solves it.
2. Update `SKILL.md` when triggers, workflow, or safety behavior changes.
3. Add or update an example request and a test-plan entry.
4. Run the validation checks described in `tests/README.md`.
5. Do not add secrets, private fixtures, or provider-specific claims without documentation and tests.
